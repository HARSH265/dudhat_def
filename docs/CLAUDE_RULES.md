# Claude Rules

Before every task:
1. Read all docs.
2. Analyze existing code.
3. Preserve architecture.
4. Preserve design consistency.

Project Goals:
- Lead Generation
- Product Showcase
- CMS Driven Content

Rules:
- No hardcoded content
- Mobile First
- SEO First
- Secure APIs
- Reusable components

When implementing:
- Explain approach first
- Mention impacted files
- Generate only required changes

Never:
- Duplicate code
- Break API contracts
- Put business logic in controllers
